## 段階式プトレマイオスモデル検証

火星の見かけの黄経に対して、天動説モデルの要素を段階的に追加しながら残差を比較するStreamlitアプリです。

モデルは次の4段階から横並びのボタンで選べます。

1. 従円のみ
2. 従円 + 周転円
3. 従円 + 周転円 + 離心円
4. 従円 + 周転円 + 離心円 + エカント

### 実行

```bash
python -m pip install -r requirements.txt
streamlit run ptolemy_app.py
```

### 観測CSV

CSVを指定しない場合は、Kepler楕円軌道から作った比較用の模擬観測を使います。これは実観測データではありません。

実データを使う場合は、次のどちらかの形式でCSVを読み込めます。

```csv
day,longitude_deg
0,123.4
5,124.1
10,125.0
```

または

```csv
date,longitude_deg
2026-01-01,123.4
2026-01-06,124.1
2026-01-11,125.0
```

`longitude_deg` は黄経を度で与えます。`date` を使う場合は最初の日を0日として内部変換します。
